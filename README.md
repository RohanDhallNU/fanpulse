# FanPulse

FanPulse helps product analysts at consumer apps turn hundreds of app reviews into a weekly ranked list of what drives customers away, so they can fix the biggest problem before ratings drop.

Built for INFO7375 (Branding & AI), Assignment 6A. Streamlit front end + Google Gemini (free tier).

Run locally: `pip install -r requirements.txt`, add `GEMINI_API_KEY = "..."` to `.streamlit/secrets.toml`, then `streamlit run app.py`.
